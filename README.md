# WK1-PM1 - Lab Setup: VirtualBox and Kali Linux

Cybersecurity testing lab for the Networkwalks internship.

## Setup
- VirtualBox with Kali Linux 2026.2 as the attacking machine
- NAT Network `NatNetwork` on 10.0.0.0/24
- Kali static IP: 10.0.0.2/24, gateway 10.0.0.1
- Clipboard and drag/drop: Bidirectional
- Shared folder: host Downloads, auto-mounted
- Full internet access verified
- Snapshot taken: "Fresh Kali 10.0.0.2"
